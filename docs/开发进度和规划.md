## 一、项目目标

一个通用的 **Windows 右键菜单管理工具**：

- 在文件夹/桌面右击空白处，直接用某个工具在**当前目录**打开（如「在 Claude Code 中打开」）。
- **自动扫描**电脑中已安装的 CLI / GUI 工具，勾选即可加入右键菜单。
- 支持**手动添加**任意自定义菜单项（VS Code、Cursor 等）。
- 每一项可**启用 / 禁用 / 编辑 / 删除 / 排序**。

## 三、核心技术方案

### 注册表挂载点（均在 `HKCU\Software\Classes` 下）
| 位置 | 父键路径 | 命令存储键 | 路径变量 |
|------|----------|------------|----------|
| background 文件夹空白 | `Directory\Background\shell\RightMenu.Tools` | `RightMenu.Store.Background` | `%V` |
| folder 文件夹本身 | `Directory\shell\RightMenu.Tools` | `RightMenu.Store.Folder` | `%V` |
| desktop 桌面空白 | `DesktopBackground\Shell\RightMenu.Tools` | `RightMenu.Store.Desktop` | `%V` |

- 分组子菜单用 **`ExtendedSubCommandsKey`** 实现（每用户可用，无需 HKLM CommandStore）。
- 父键设 `MUIVerb`（显示名）+ `ExtendedSubCommandsKey`（指向命令存储，相对 HKCR 解析）。
- 子项写在 `<store>\shell\{order:03}_{id}`，用 `MUIVerb` 显示、`command` 默认值为最终命令。

### 启动命令渲染（`launcher.rs`）
内层模板占位符：`{exe}`（替换为带引号的可执行文件路径）、`%V`（当前目录，注册表运行时解析）。

- **GUI**：`.exe` 直接执行 `"exe" "%V"`；`.cmd/.bat` 用 `cmd /c` 包裹。
- **CLI**：按所选终端在 `%V` 目录运行：
  - `wt`：`wt.exe -d "%V" cmd /k "{exe}"`
  - `cmd`：`cmd.exe /s /k "cd /d "%V" && "{exe}""`
  - `powershell/pwsh`：`-NoExit -Command "Set-Location ...; & {exe}"`

### 启用/禁用与「应用」模型
- 配置为唯一事实来源；点击「应用」执行**全量同步**：先 `cleanup()` 删除本工具所有键，再按 `enabled` 项重建 → 杜绝脏键。
