## 三、已交付能力（P0 核心闭环）

- **扫描分类**：HKCU/HKLM 分读、HKCR 合并语义、同名遮蔽、LegacyDisable/Extended/HideBasedOnVelocityId/AppliesTo/ProgrammaticAccessOnly/DelegateExecute/子菜单/未知结构全覆盖；本机 16 项全部正确分类（含旧版 `RightMenu.codex` 识别为遗留项、12 个 HKLM 项标记"可迁移"）。
- **启动链**：`受管项 → App broker（无窗口）→ wt.exe / 经典控制台 → Runner → CLI`；工作目录走 `WorkingDirectory`，参数走数组，`.cmd/.bat` 经集中的 `CmdScriptLauncher` 全引号调用；wt 的 `;` 转义已处理。特殊字符目录（空格/中文/&/()/'/;）× `.exe/.cmd/.bat` 全矩阵 18 用例通过。
- **CLI 发现**：进程/用户/系统 PATH + PATHEXT + App Paths + `.local\bin`/npm/pnpm/bun；本机实测发现全部已装 CLI（claude/codex/gemini/kiro×2/opencode×2），Antigravity 如实报未装。
- **CRUD 与安全**：稳定 GUID 键名 schema v1；目标键级 before/after 快照 + 最近 50 次操作日志 + 逐级撤销；乐观并发检查（冲突拒绝写入/撤销不覆盖）；编辑保留未知值与子键；HKLM 写入被 Core 层拒绝。
- **HKLM 迁移**（02 §7.4）：复制→验证→一次 UAC 提权删除原键（`--elevated-delete` 白名单 helper）；UAC 拒绝时如实显示"已遮蔽"。
- **UI**：单列表 + 位置文字 + Inspector（新建/编辑/查看/迁移/升级共用）；添加 CLI 两步流程（发现列表→预填保存）；搜索/筛选/高级项开关；状态栏撤销；删除确认（默认焦点取消）；快捷键 Ctrl+F/Ctrl+N/F5/Esc/Enter/Space/Delete；深浅主题跟随；应用图标（`scripts/make-icon.ps1` 程序化生成）。
- **设置**：经典菜单实验性开关（精确快照可逆 + Windows 版本显示 + Explorer 重启确认）、操作历史、显式 `.reg` 导出。

## 六、开发环境备忘

- 本机 `DOTNET_ROOT`/PATH 默认指向 `C:\Users\admin\Tools\dotnet`（仅 8.x），.NET 10 在 `C:\Program Files\dotnet`；`build.ps1` 自动切换，手动 `dotnet` 命令需先设环境变量。
- 解决方案文件为 `RightMenu.slnx`（.NET 10 默认格式）；`global.json` 锁定 SDK 10.0.302。
- 自包含发布产物在 `artifacts\publish\`；右键菜单受管项应指向发布版（或未来的安装路径），不要指向 Debug 输出。
- 验证脚本：`scripts/test-runner-cwd.ps1`（cwd 矩阵）、`scripts/test-runner-matrix.ps1`（全矩阵）、`scripts/make-icon.ps1`（重新生成图标）。
- 测试纪律：自动化测试只写 `RightMenu.Test.<GUID>` ProgID 与内存 fake，不碰真实菜单键。
